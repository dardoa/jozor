## 3. Neutral 1:1 Layout Comparison Conditions

To evaluate **Focus Mode (`حول شخص`)** vs. **Radial Mode (`دائري / مروحي`)** side-by-side without bias, both comparison mockups (`comparison-focus-a2-classic-1440x900.html` and `comparison-radial-a2-classic-1440x900.html`) were generated using **strictly identical conditions**:

- **Sanitized Dataset Fixture:** Same 15-person family tree (`عائلة سليمان الكبير`, root, parents, grandparents, children, siblings, spouse).
- **Document Format:** Exact same **A2 Landscape** canvas.
- **Style Preset:** Exact same **Classic Heritage (`التراث الكلاسيكي`)** warm palette (`#f4ead8` background, `#fffaf0` card fills, `#a86f35` borders).
- **Content Visibility:** Identical card details (names, relationships, circular photos).
- **Detail Density:** Equivalent text scaling and card margins.

## 4. Key UX Corrections & Features Implemented

1. **Interactive Quick Setup Area:**
   - Placed near top of header bar on both desktop and mobile.
   - Includes real selectable controls: Product Mode, Layout Engine (`حول شخص` / `دائري / مروحي` / `متدرج`), Scope, Preset, Page Size, Orientation, and Print Quality status.
2. **Owner-Facing Terminology (Pure Arabic User Terms):**
   - Removed all internal engine IDs (`focus-family`, `radial-generations`, `ancestor-tiered`) from UI labels.
   - Used clean user terms: `حول شخص`, `دائري / مروحي`, `متدرج`, `شكل العرض`, `عدد الأجيال`, `إعدادات متقدمة`.
3. **Large Radial Canvas Composition:**
   - Enlarged Radial composition to fill the primary preview pane.
   - 4-5 concentric rings radiating smoothly across the canvas.
   - Straight horizontal Arabic text badges used for 100% legibility without Naskh arc distortion.
4. **Inspectable Large-Tree Quality Warning:**
   - Moved quality warning box from covering the poster canvas into the settings workspace / quality panel.
   - Left the dense micro-card preview fully inspectable.
   - Retained actionable recommendations: Upgrade to A0, Dense Genealogy preset, Branch Collection ZIP, or Tiled Wall 3×3 grid.
5. **Mobile Layout Corrections:**
   - Enlarged preview pane to a useful height (260px).
   - Removed excessive vertical space.
   - Reserved safe bottom padding for fixed export bar.
   - Ensured SVG / PNG / PDF export buttons are 100% visible and unclipped.
   - Included persistent compact print-quality summary (` Pass • 300 DPI • A2`).
   - Placed secondary settings in an `إعدادات متقدمة` bottom sheet trigger.
6. **Visible State Controls:**
   - `تراجع` (Undo) button
   - `إعادة` (Redo) button
   - `استعادة القسم` (Reset section) button
   - `استعادة اللوحة بالكامل` (Reset poster) button
   - `معدّل` (Modified preset badge) when an override is present
