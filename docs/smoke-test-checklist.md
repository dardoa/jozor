# Jozor Smoke Test Checklist

هذه القائمة هي خط الأساس العملي قبل دمج أي تغيير في مسارات الرسم، المزامنة، الحالة، أو التنسيق العام. الهدف هو اكتشاف regressions بسرعة قبل أن تتحول إلى مشاكل نشر.

## Automated Smoke

شغل الاختبار الآلي الأساسي:

```powershell
npm run test:e2e:smoke
```

هذا السكربت يستخدم:

```text
tests/e2e/app-smoke.spec.ts
```

ويغطي حاليًا:

- تحميل shell التطبيق.
- فتح شجرة debug.
- صلاحيات viewer/editor/owner.
- تعديل شخص واستمرار القيمة بعد reload.
- فتح إعدادات الشجرة والمشاركة.
- diagnostics وsync telemetry.
- invitation telemetry.
- بعض مسارات shared-tree smoke.

## Manual Smoke

نفذ هذه القائمة يدويًا قبل دمج حزمة كبيرة أو نشر production:

### Startup

- افتح التطبيق.
- تأكد أن شاشة البداية تختفي.
- تأكد أن التطبيق لا يبقى عالقًا عند غياب جلسة Supabase.
- تأكد أن landing/local mode يظهران للمستخدم غير المسجل.

### Tree Basics

- افتح شجرة موجودة.
- أنشئ شجرة جديدة.
- تأكد أن اسم الشجرة يظهر في الهيدر.
- غيّر الشجرة النشطة من Tree Selector أو The Vault.

### Editing

- أضف شخصًا.
- عدّل بيانات شخص.
- احذف شخصًا.
- أضف علاقة أب/أم/ابن/زوج.
- تأكد أن العلاقات لا تنتج حلقة واضحة أو حالة مكسورة.

### Undo / Redo

- نفذ تعديلًا بسيطًا.
- اضغط undo.
- اضغط redo.
- تأكد أن الرسم والبيانات متزامنان بعد كل خطوة.

### Rendering

- جرّب التكبير والتصغير.
- حرّك الشجرة.
- افتح شجرة متوسطة أو كبيرة إن توفرت.
- تأكد من عدم وجود تجمد واضح أو بطاقات مفقودة.

### Auth

- سجل الدخول.
- سجل الخروج.
- أعد تحميل الصفحة بعد تسجيل الدخول.
- تأكد أن آخر شجرة أو وضع العمل يعود بشكل منطقي.

### Vault

- افتح The Vault.
- انتقل بين تبويبات:
  - Export & Cloud
  - Security
  - Trees
  - Members
  - Stats
- تأكد أن زر الرجوع أو الإغلاق يعمل.

### Google Drive Backups

- اربط Google Drive.
- اعرض ملفات النسخ الاحتياطي.
- أنشئ نسخة احتياطية جديدة.
- افتح نسخة احتياطية موجودة.
- جرّب حذف ملف غير نشط إن كان آمنًا.

### Sharing

- افتح مشاركة الشجرة.
- أنشئ دعوة viewer.
- أنشئ دعوة editor.
- اقبل دعوة من حساب مناسب أو سيناريو debug.
- تأكد أن viewer لا يستطيع التعديل.
- تأكد أن editor يستطيع التعديل.

### Discussions

- افتح المحادثات.
- أضف رسالة.
- احذف رسالة أو ردًا إن كان المسار متاحًا.
- تأكد أن واجهة المحادثات لا تكسر الرسم.

### Export

- صدّر JSON.
- صدّر Jozor archive.
- صدّر PNG أو PDF.
- تأكد أن export لا يترك The Vault أو modals في حالة عالقة.

### Admin

- افتح قائمة الحساب كـ admin.
- افتح Kindi Learning Reports.
- تأكد أن الصفحة قابلة للتمرير.
- افتح Default Tree Settings.
- عدّل قيمة آمنة واحفظها.
- تأكد أن المستخدم غير admin لا يرى روابط Admin.

## Required Verification Before Merge

قبل دمج أي حزمة عالية التأثير، شغل:

```powershell
npx tsc --noEmit --pretty false
npm run build
npm run test
npm run test:e2e:smoke
```

للحزم الصغيرة يمكن الاكتفاء باختبارات نطاقية، لكن أي تغيير في rendering أو sync أو auth يحتاج القائمة الكاملة.

## Failure Policy

إذا فشل smoke:

1. لا تدمج الحزمة.
2. سجّل اسم الاختبار أو الخطوة اليدوية الفاشلة.
3. صنّف الفشل:
   - startup
   - rendering
   - editing
   - sync
   - auth
   - vault
   - sharing
   - admin
4. أصلح السبب أو اعزل الحزمة.
5. أعد تشغيل الاختبار المرتبط على الأقل.
